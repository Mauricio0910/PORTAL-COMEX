Você abriu o arquivo HTML diretamente.

O visual agora pode aparecer, mas o login, os formulários e o envio da ND2 só funcionam com o servidor ativo.

  1. Extraia o arquivo ZIP em uma pasta do computador.
  2. No Windows, abra INICIAR_PORTAL_WINDOWS.bat (é necessário ter Python 3.10 ou superior).
  3. Crie a conta do professor quando solicitado, caso seja o primeiro acesso.
  4. Abra http://127.0.0.1:8080 no navegador.

Para receber entregas de diferentes casas ou computadores pela internet, a faculdade deverá hospedar este servidor com HTTPS e banco de dados persistente.
